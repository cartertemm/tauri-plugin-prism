## Default Permission

Allows every prism speech command

#### This default permission set includes the following:

- `allow-speak`
- `allow-stop`
- `allow-info`
- `allow-voices`
- `allow-set-voice`
- `allow-set-rate`
- `allow-set-pitch`
- `allow-set-volume`
